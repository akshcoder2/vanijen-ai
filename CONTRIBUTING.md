# Contributing

On Windows 10/11 with Python installed, run `setup.bat`. Try opening the compact widget, hovering, switching characters, and expanding or collapsing the panel. Use a personal Sarvam key only for optional live API tests. Never attach `.env`, recordings, screenshots, or keys to a PR.

In a UI bug report, include Windows and Python versions and list the steps to reproduce. For media changes, provide the asset source and redistribution terms.
