# Assets

The repository package includes AI-generated character portraits, derived cutouts and original project icon assets created for Vanijen AI. They are separate from the MIT software license. Check the image provider's terms before redistributing art independently.

The privately supplied Vaani videos are not included in the public package. To add your own clips for local use, place them at `assets/vaani/idle.mp4`, `assets/vaani/listening.mp4`, and `assets/vaani/thinking.mp4`. Vanijen AI uses the static Vaani portrait when a clip is missing. Do not publish clips unless you have redistribution rights.
